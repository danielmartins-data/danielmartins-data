# Segurança e privacidade dos dados

- Este repositório **não contém dados reais**: todas as bases são sintéticas, geradas por script com seed fixa.
- Nenhuma credencial, token ou chave de API é versionada. Variáveis sensíveis nunca entram no código.
- Se encontrar um problema (por exemplo, um dado que pareça real), abra uma issue ou envie e-mail para dfm21031983@gmail.com.
